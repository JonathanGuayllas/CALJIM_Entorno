# Proyecto CALJIM

Plataforma web para la gestión de material pétreo, transporte y alquiler de maquinaria pesada en Paquisha, Zamora Chinchipe.

## Estado actual del proyecto
- **Entorno de desarrollo**: Configurado con PHP 8 y Laravel 11 (Arquitectura MVC).
- **Base de datos**: Modelo relacional de 12 tablas implementado en MySQL (`caljim_db`).
- **Autenticación**: Pantalla principal, Login y Registro de usuarios funcionales con encriptación de contraseñas (`Bcrypt`) y control de roles.

*El proyecto continúa en desarrollo para la implementación de los demás módulos operativos.*
